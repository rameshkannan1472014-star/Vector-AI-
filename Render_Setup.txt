Engineer AI - Render setup (updated)

Upload index.html, server.py and requirements.txt (unchanged) to GitHub. Set these in Render > Environment, then redeploy.

FEEDBACK EMAIL (works on Render free tier, uses HTTPS not SMTP)
1. Make a free account at resend.com using the SAME Gmail address that should receive feedback.
2. Create an API key and set:  RESEND_API_KEY = re_...
3. Optional: FEEDBACK_TO_EMAIL = your email (overrides the address in server.py)
Note: Render free blocks SMTP ports (25/465/587). Do not rely on SMTP_PASSWORD there.

SPEED
GROQ_API_KEY               -> now used FIRST for normal chat (fast). Gemini is the backup.
PRIMARY_CHAT_PROVIDER      -> optional; "groq" (default) or "gemini"
GROQ_REASONING_EFFORT      -> optional; low (default) / medium / high
HISTORY_MESSAGES / HISTORY_CHARS -> now default 10 / 1200 (was 24 / 2000)
Keep-alive: create a free UptimeRobot monitor for https://YOUR-APP.onrender.com/api/health every 5-10 minutes so the free service does not fall asleep.

PHOTOS
CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_API_TOKEN (Workers AI permission) -> now tried FIRST. Gemini is the backup.

VIDEO
Needs a billing-enabled Gemini project (Veo). If you do not have one, set ENABLE_VIDEO = false and the app shows "coming soon" instead of an error.

CHECK
Open /api/health after redeploying. Under "providers" you should see:
groq_coding_fallback: true, cloudflare_image_fallback: true, feedback_email: true, chat_primary: "groq".
Never share screenshots that show API keys; rotate any key that was exposed.
